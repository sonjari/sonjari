# Security

Please do **not** open a public issue for a security problem.

Email **hello@sonjari.com** with:

- what you found and how to reproduce it,
- the Sonjari version (Settings › General) and how it was installed (Microsoft Store or from source),
- whether it needs anything unusual to trigger (a specific site, a connected AI tool, a pack).

We will reply within a few days, tell you what we found, and credit you in the release notes unless you ask us not to.

Things we especially want to hear about:

- anything that lets a web page, a document or a connected AI approve an irreversible action (send, publish, pay, delete)
  without the approval card in the app window,
- anything that makes Sonjari read or write outside the folders the user allowed,
- anything that sends conversation or file content off the PC other than a problem report the user chose to send,
- instructions hidden in a page or file that Sonjari follows as if the user had written them.

Do not send exploit code as an archive attachment; paste text or link a private gist.
