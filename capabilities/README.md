# 손자리 기능 카드 — 부모 에이전트(클로드 · 코덱스)용

손자리(Sonjari)가 **무엇을 할 수 있는지**를 기능 하나 = 파일 하나로 적었다. 통째로 읽지 말고 찾아서 읽는다.

```
grep -ril "참조" .          # 한국어로
grep -ril "reference" .     # 영어로
```

카드 머리의 `필요:` 를 먼저 본다(팩 켜기 · 프로그램). `맡기기:` 가 `직접` 이면 그 도구를 당신이 부르고,
`맡기기` 면 `sonjari_task` 에 「이렇게 맡기세요」의 문장을 넣는다.

## 분류

| 폴더 | 무엇 |
|---|---|
| `game/` | 유니티 — 프로젝트 점검 · 레시피 · 열린 에디터에서 같이 만지기 |

(나머지 분류는 차례로 채운다: browser · files-docs · code · animator · video · remote-mac · schedule · model-hw)

## 카드 틀

머리(`---` 사이): `id` · `분류` · `제목` · `찾는말`(한 · 영) · `도구` · `맡기기`(직접 | 맡기기 | 둘 다) · `필요` · `확인일`.
본문 절: 되는 것 · 안 되는 것 · 알려진 막힘 · 이렇게 맡기세요 · 끝났는지 보는 법 · 잰 것.

- 「잰 것」의 숫자에는 날짜 · 조건을 붙인다. 잰 적 없으면 「아직 안 잼」.
- 카드 한 장은 4KB 이하(한글은 글자당 3바이트).
- 손자리가 내보내는 도구는 전부 어느 카드엔가 있어야 한다 — `tests/test_capability_cards.py` 가 막는다.
