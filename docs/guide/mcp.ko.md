# 클로드 코드, 코덱스, 커서에서 손자리 쓰기 (MCP)

[English](mcp.md) · **한국어**

손자리는 내 PC 에서 로컬 모델로 돕니다. 클로드 코드, 클로드 데스크톱, 코덱스, 커서 같은 다른 AI 가
[MCP](https://modelcontextprotocol.io) 로 손자리에게 일을 통째로 맡길 수 있습니다. 「웹에서 찾아서 엑셀로 정리해 줘」나 「내 저장소의
이 시험 좀 고쳐 줘」 같은 일입니다. 손자리는 페이지와 파일을 이 PC 에서 읽기 때문에, 그 본문이 맡긴 AI 의 대화 창에 들어가지 않습니다.
맡긴 AI 는 답과 만든 파일, 읽은 출처, 확인하지 못한 것만 돌려받습니다.

## 연결하기

### 제일 쉬운 방법: 「연결」 단추

손자리에서 **설정 › 연결**로 가서, 쓰는 앱 옆의 **연결**을 누르면 됩니다. 손자리가 원래 설정 파일을 먼저 백업해 두고 `sonjari` 라는
항목 하나만 더합니다.

| 앱 | 항목이 들어가는 곳 | 방법 |
|---|---|---|
| 클로드 코드 | 사용자 범위 (`claude mcp add-json … --scope user`) | `claude` 명령으로 넣습니다. `.claude.json` 을 직접 고치지는 않습니다 |
| 클로드 데스크톱 | `%APPDATA%\Claude\claude_desktop_config.json` 의 `mcpServers` (스토어판 클로드는 패키지 폴더 안의 같은 파일에도) | 파일을 고치고, 원본은 백업합니다 |
| 커서 | `~/.cursor/mcp.json` 의 `mcpServers` | 파일을 고치고, 원본은 백업합니다 |
| 코덱스 | `codex mcp add` 가 있으면 그걸로, 없으면 `~/.codex/config.toml` 의 `[mcp_servers.sonjari]` | 명령이나 파일 수정 |

연결한 다음에는 그 앱을 다시 켜 주세요. 클로드 데스크톱은 완전히 꺼야 하는데, 손자리가 꺼질 때까지 기다려 줍니다.

연결하면 맡긴 AI 가 읽을 짧은 사용법도 같이 설치됩니다.

| 앱 | 사용법 파일 | 그 파일을 가리키는 줄이 들어가는 곳 |
|---|---|---|
| 클로드 코드 | `~/.claude/skills/sonjari-guide/SKILL.md` | `~/.claude/CLAUDE.md` |
| 코덱스 | `~/.codex/sonjari-guide.md` | `~/.codex/AGENTS.md` |
| 커서 | 없음 (사용자 규칙이 앱 안에 있어서, 붙여 넣을 글을 보여 드립니다) | 없음 |
| 클로드 데스크톱 | 없음 (다른 앱이 스킬을 넣을 수 없습니다). 대신 처음에 `sonjari_guide` 도구를 한 번 부르면 됩니다 | 없음 |

### 직접 설정할 때

항목에는 비밀 값이 들어가지 않습니다. 스토어판이라면 이런 모양입니다. 「연결」을 누르면 손자리가 실제 경로를 채워 주니, 가능하면
거기서 복사해 오는 게 제일 정확합니다.

```json
{
  "mcpServers": {
    "sonjari": {
      "command": "%LOCALAPPDATA%\\Microsoft\\WindowsApps\\sonjari-mcp.exe",
      "args": ["-m", "alture_jarvis.mcp_server"],
      "env": {
        "PYTHONIOENCODING": "utf-8",
        "JARVIS_BASE_URL": "http://127.0.0.1:8091",
        "JARVIS_TOKEN_FILE": "<손자리 control.token 파일 경로>",
        "JARVIS_MCP_MAX_RISK": "L1"
      }
    }
  }
}
```

소스로 빌드해서 쓰신다면 `command` 는 `.venv\Scripts\python.exe` 가 되고, `env` 에 `src` 를 가리키는 `PYTHONPATH` 가 하나 더 들어갑니다.

코덱스는 `~/.codex/config.toml` 에 이렇게 넣습니다.

```toml
[mcp_servers.sonjari]
command = "<같은 명령>"
args = ["-m", "alture_jarvis.mcp_server"]
env = { PYTHONIOENCODING = "utf-8", JARVIS_BASE_URL = "http://127.0.0.1:8091", JARVIS_TOKEN_FILE = "<경로>", JARVIS_MCP_MAX_RISK = "L1" }
```

| 변수 | 뜻 |
|---|---|
| `JARVIS_BASE_URL` | 손자리 로컬 백엔드 주소입니다. `127.0.0.1` 에서만 듣고, 네트워크에는 열려 있지 않습니다 |
| `JARVIS_TOKEN_FILE` | 로컬 토큰이 들어 있는 파일입니다. 토큰 값 자체는 설정에 적지 않습니다 |
| `JARVIS_MCP_MAX_RISK` | 밖으로 내보낼 도구의 위험 단계 상한입니다. 기본값 `L1` 이면 되돌릴 수 없는 동작은 아예 내보내지 않습니다 |
| `JARVIS_MCP_INCLUDE` / `JARVIS_MCP_EXCLUDE` | 쉼표로 이은 도구 이름입니다. 꼭 넣을 것과 뺄 것을 정합니다(겹치면 넣기가 이깁니다) |
| `JARVIS_MCP_EXCLUDE_PREFIXES` | 기본으로 숨기는 도구 이름 머리입니다. `camera_`, `ui_` |

## 도구

기본으로 있는 도구는 세 개입니다. 분야 팩을 켜면 그 팩의 도구가 더해집니다(게임 팩을 켜면 `unity_*` 가 생기는 식입니다).

### `sonjari_task`: 일 하나를 통째로 맡기기

부르면 바로 `job_id` 를 돌려줍니다. 무엇을, 어디서, 어떤 파일로 받고 싶은지를 한 문장에 담아 주세요. 브라우저 도구를 하나하나
부르는 것보다 이 도구를 한 번 부르는 쪽이 빠르고 토큰도 덜 씁니다.

| 칸 | 종류 | 꼭 넣어야 하나 | 하는 일 |
|---|---|---|---|
| `task` | 글 | 예 | 맡길 일을 한 문장으로. 사용자가 쓰는 언어로 적으면 됩니다(최대 4,000자) |
| `needs` | 글 목록 | 아니요 | 꼭 돌려받아야 할 항목 이름을 12개까지 적습니다. 예: `["상품 이름", "가격", "주소"]`. 결과에 항목마다 채웠는지(`met: true / false / null`)가 옵니다. 전화번호와 메일 주소는 여기 적었을 때만 나가고, 주민번호, 카드 번호, 비밀 키는 언제나 가립니다 |
| `repo` | 글 | 아니요 | 코드 일을 맡길 때 씁니다. 이 PC 에 있는 git 저장소(또는 그 안의 폴더)의 절대 경로입니다. 손자리는 새 가지를 따로 꺼내서 거기서만 고치고, 내 폴더는 건드리지 않습니다. 커밋하지 않은 변경(추적 중인 파일)도 같이 가져갑니다 |
| `check` | 글 | 아니요 | `repo` 와 같이 씁니다. 「다 됐다」를 가르는 명령 한 줄입니다. 그 폴더에서 돌려서 종료 코드가 0 이면 통과입니다. 예: `python -m pytest -q tests/test_x.py`. 통과할 때까지 고치고, 끝내 못 하면 못 했다고 알려 줍니다 |
| `skill` | 글 | 아니요 | 쓸 스킬 이름입니다. 잘 모르면 비워 두세요 |

저장 폴더는 적지 않는 게 기본입니다. 결과 파일은 `문서\Sonjari` 에 저장되고, 경로는 `files` 로 돌아옵니다. 다른 폴더를 적으면
손자리 창에서 사람이 승인해야 하고, 승인할 때까지 일이 멈춰서 기다립니다.

### `sonjari_task_status`: 진행 상황과 결과 받기

| 칸 | 종류 | 꼭 넣어야 하나 | 하는 일 |
|---|---|---|---|
| `job_id` | 글 | 예 | `sonjari_task` 가 돌려준 번호 |
| `wait_sec` | 정수 | 아니요 | 답하기 전에 최대 이만큼 기다립니다. 기본값이자 상한은 클로드 코드가 240초, 다른 앱은 50초입니다. 웬만하면 비워 두세요. 물어볼 때마다 맡긴 AI 가 대화 전체를 다시 읽어야 합니다 |

### `sonjari_guide`: 첫 일을 맡기기 전에 한 번 읽기

「연결」을 누를 때 스킬로 설치되는 것과 같은 사용법을 돌려줍니다. 과제를 어떻게 적는지, 결과를 어떻게 전하는지, 막혔을 때
어떻게 하는지가 들어 있습니다. 읽기만 하고 아무것도 바꾸지 않습니다.

## 돌려받는 것

일이 끝나면 `sonjari_task_status` 가 이런 칸을 돌려줍니다.

| 칸 | 내용 |
|---|---|
| `status` | 아래 [상태가 바뀌는 순서](#상태가-바뀌는-순서) 참고 |
| `answer` | 손자리의 답 |
| `files` | 만든 파일의 경로 |
| `sources` | 실제로 읽은 주소와 파일 |
| `unsupported_numbers` | 답이나 파일에 있는데, 어떤 도구도 준 적 없는 숫자입니다. 사실처럼 전하면 안 됩니다 |
| `needs` | 적어 준 항목마다 `met` 값이 옵니다. `true` 는 값이 있음, `false` 는 자리가 비어 있음, `null` 은 그 자리를 못 찾았다는 뜻입니다(비어 있다는 뜻이 아니니 답을 직접 확인해 주세요) |
| `completion_state` | `complete`(다 함) 또는 `partial`(일부만 함) |
| `review_notes` | 답을 전하기 전에 읽어 볼 짧은 메모 |
| `resume` | 일이 덜 끝났을 때 붙습니다. `evidence` 는 이미 읽은 곳(다시 열 필요 없음), `next` 는 남은 일입니다 |
| `branch` | 코드 일의 결과입니다. `name`, `changed`, `changed_count`, `stat`, `check`(통과 여부), `wording_only`(설명 글이나 주석만 바뀐 파일), `take_home`(`review` / `take` / `discard` 명령) |
| `cost` | 걸린 시간, 이 PC 에서 읽은 페이지 수, `host_context_kept_out.tokens_at_least` 입니다. 마지막 값은 적게 잡은 값(하한)이고, 어떻게 셌는지(`basis`)가 같이 옵니다 |
| `receipt` | 사용자에게 보여 줄 한 줄 요약 |

일하는 중에는 `progress.doing`(지금 하는 일), `progress.requested`(시킨 것 중 몇 개를 했는지), `steps` 가 오고, 줄 서 있는 동안에는
`jobs_ahead` 가 옵니다. 손자리는 한 번에 한 가지 일만 합니다.

## 상태가 바뀌는 순서

| `status` | 뜻 | 맡긴 AI 가 할 일 |
|---|---|---|
| `queued` | 다른 일 뒤에서 기다리는 중 | 조금 있다 다시 물어보면 됩니다 |
| `running` | 일하는 중 | `progress.doing` 을 한 줄로 전하고 다시 물어봅니다 |
| `needs_approval` | 되돌릴 수 없는 단계나 질문이 손자리 창에서 사람을 기다리는 중 | 손자리 창을 봐 달라고 사용자에게 알립니다. 대신 답하면 안 됩니다 |
| `needs_decision` | 같은 자리에서 막혔거나, 로그인 · 보안 문자 · 결제 화면을 만남 | `message` 를 그대로 전합니다. 로그인과 보안 문자는 사람이 끝내면 손자리가 알아서 이어 가니 계속 물어보면 됩니다 |
| `done` | 끝남 | `answer`, `files`, `sources` 를 전합니다 |
| `needs_review` | 끝났지만 도구가 준 적 없는 숫자가 답에 있음 | 그 숫자는 확인이 필요하다고 알립니다 |
| `failed` / `cancelled` | 멈춤 | 그래도 `files`, `sources`, `resume` 은 멈추기 전까지 한 일이니 버리지 말고 씁니다 |

## 이렇게 써 보세요

**조사해서 파일로 받기**

```text
sonjari_task(task="사람인에서 서울 마케팅 공고 3개 찾아서 회사 · 마감일 · 링크를 엑셀로 정리해줘",
             needs=["회사", "마감일", "링크"])
sonjari_task_status(job_id=...)   # wait_sec 은 비워 두기
```

**확인 명령이 있는 작은 코드 일 맡기기**

```text
sonjari_task(task="시험은 고치지 말고 test_parse_dates 가 통과하게 해줘",
             repo="C:/work/myapp",
             check="python -m pytest -q tests/test_dates.py")
```

다 되면 바뀐 걸 먼저 보고 가져오세요.

```powershell
git -C C:/work/myapp diff <base>..sonjari/task-<n>            # branch.take_home.review
git -C C:/work/myapp cherry-pick -n <base>..sonjari/task-<n>  # branch.take_home.take
```

손자리에게는 확인 명령이 분명한 작은 일(파일 한두 개 정도)을 맡기는 게 잘 됩니다. 큰 설계나 처음 보는 API 를 쓰는 일은 맡긴 AI 가
직접 짜고, 손자리에게는 적용하고 시험 돌리는 일만 시키는 편이 낫습니다.

## 한계와 안전

- 손자리는 `127.0.0.1` 에서만 요청을 받습니다. MCP 설정에는 토큰이 아니라 토큰 파일의 경로만 들어갑니다.
- 되돌릴 수 없는 일(메일 보내기, 글 올리기, 결제, 삭제)은 기본 설정 `L1` 에서 밖으로 내보내지 않습니다. 이런 일은 사람이 손자리
  창에서 직접 합니다.
- 로그인, 보안 문자, 결제 화면은 사람에게 넘깁니다. 손자리는 보안 문자를 풀지 않습니다.
- 코드 일을 해도 내 작업 폴더는 그대로입니다. 따로 만든 가지만 바뀌고, 그 가지는 보고 가져가거나 버리면 됩니다.
- 로컬 모델은 클라우드 모델보다 느립니다. 손자리가 아껴 주는 건 맡긴 AI 의 대화 창과 사용 한도이고, 더 빠르다고는 말하지 않습니다.
- 무엇이 PC 밖으로 나가는지는 [내 PC 밖으로 나가는 것과 안 나가는 것](privacy.ko.md)에 그림으로 정리해 두었습니다.

## 잘 안 될 때

| 이런 증상이면 | 이걸 확인하세요 |
|---|---|
| 앱 목록에 `sonjari` 가 안 보임 | 연결한 뒤 그 앱을 다시 켰는지 확인하세요. 클로드 데스크톱은 완전히 끄고 다시 켜야 합니다 |
| 도구는 보이는데 부르면 연결 오류가 남 | 손자리가 꺼져 있는 겁니다. 손자리를 켜면 백엔드도 같이 켜집니다 |
| 부를 때마다 `queued` 에서 기다림 | 다른 일이 돌고 있는 중입니다. 손자리는 한 번에 하나씩 합니다 |
| `needs_approval` 에서 계속 멈춰 있음 | 손자리 창에 뜬 카드에 누군가 답해야 합니다 |
| 코드 일을 거절함 | `repo` 가 이 PC 의 git 저장소인지, 손자리가 쓸 수 있게 허락한 폴더 안에 있는지 확인하세요 |
